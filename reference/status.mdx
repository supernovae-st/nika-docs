<Info>
  This page is judged by the **downloadable release**, the binary a new
  reader installs. `version` and `lastUpdated` come from that GitHub
  release via `scripts/mintlify-snapshot.sh`. The provider count is the
  length of `nika catalog --json` on that same binary.

  Crate, test, ADR, hygiene, and capability-rule totals do **not** project
  from the binary. They used to sit on this page next to the release
  number and destablize first-time readers (a July engine-`main` SHA next
  to a later release). They are gone from here. The engine repo still
  carries them in its own `refresh-status.sh` block.
</Info>

## How to refresh

```bash
bash scripts/mintlify-snapshot.sh           # version + lastUpdated ONLY
nika catalog --json                         # provider length must match STATUS.providers
```

Crate, test, ADR, and hygiene totals belong in the engine repo
(`bash scripts/refresh-status.sh`). Do not copy them back onto this page.

## Drift protection, stated honestly

<Warning>
  `scripts/mintlify-snapshot.sh` only rewrites `version` and `lastUpdated`.
  A fresh date is evidence about the **release**, nothing else. The
  provider count on this page must match `nika catalog --json` on that
  release binary. Engine hygiene vector 23 guards crate/test claims
  **inside the engine repo** and cannot see this one.
</Warning>

## What's admitted today

The admitted crate set lives in the engine repo's `refresh-status.sh`
block (`ROADMAP.md`, `.claude/CLAUDE.md`), judged there by hygiene vector
23. This page does not copy those totals: they are not a fact about the
binary a reader downloads.

## What's locked (decisions the project won't revisit)

- **Crate count is a projection, never a gate**: ADR-037; crates are admitted when they pass the 12 gates, reached additively across 1.x minors.
- **Real semver toward 1.0**: 0.90.0 is the first public release-candidate; 1.0 ships when release gates are green. Quality over speed.
- **Layer discipline**: L0 zero I/O, L0.5 traits only, strict downward deps, cargo-deny enforced. See [Layers](/architecture/layers).
- **12 gates per crate**: no exceptions. See [Admission](/architecture/admission).
- **Zero `.unwrap()` / `.expect(` in `src/`**: `?` propagation; `workspace.lints.clippy.unwrap_used = "deny"`.
- **Not an extraction**: every crate written fresh, legacy as reference only.
- **TDD with mutation ≥ 90%**: RED before GREEN; `cargo mutants -p <crate>` gates admission.
- **`#[non_exhaustive]` on every public type**: see [Forward-compat invariants](/architecture/forward-compat-invariants).

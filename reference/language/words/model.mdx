## In a source template

Excerpt from `templates/agent-loop.nika`, source lines 29–38. This is a fragment, not a runnable workflow.

```yaml illustration
# This skeleton keeps its authored offline model. Creating a workflow does
# not select a paid provider from ambient credentials. Choose a different
# model explicitly for a real run; `--model mock/echo` remains offline.
model: mock/echo

inputs:
  goal:
    type: string
    required: true
    # A `required:` input still carries a `default:` here so the skeleton
```

A skeleton may show `required: true` next to `default:` so the compiled file can run immediately. That pair is not the usual app contract: a required input with no default is a HINT at `nika check` and `NIKA-1708` at `nika run` until you pass `--var` or SDK `inputs`.

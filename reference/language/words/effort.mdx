## Meaning and placement

###  → run → reasoning

The EXACT native effort value the selected route advertises for the selected model (e.g. `high` where the route offers it) · forwarded verbatim as that route's own option, never translated · there is no universal effort scale. Nonempty, no surrounding whitespace (the Unicode White_Space property, spelled out in the pattern so every validator agrees; inner characters are kept as written), a literal (never a `${{ }}` template). A value the route does not offer refuses before inference; this schema does not judge which values a route offers.

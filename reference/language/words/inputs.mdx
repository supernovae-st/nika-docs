## In a source template

Excerpt from `templates/agent-loop.nika`, source lines 31–40. This is a fragment, not a runnable workflow.

```yaml illustration
# model explicitly for a real run; `--model mock/echo` remains offline.
model: mock/echo

inputs:
  goal:
    type: string
    required: true
    # A `required:` input still carries a `default:` here so the skeleton
    # RUNS the moment it is scaffolded. Replace the default with your job;
    # `--var goal=…` overrides it at any time.
```

The pinned schema text says a `required` input is not satisfied by `default` (the caller must supply a value). Published CLI 0.120.1 still applies `default:` when the key is omitted. That is a source-versus-implementation discrepancy, not one law. Prefer `required: false` plus `default:` for knobs, and required without `default:` for caller-owned values (`NIKA-1708` at run).

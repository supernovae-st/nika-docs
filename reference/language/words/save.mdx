## Meaning and placement

### agent → images

Where the engine writes the received bytes: the first image at this path, image n (n &gt;= 2) with `-n` before its extension. Judged against `permits.fs.write` before any byte is written; `${{ }}` allowed. No image received fails NIKA-AGENT-007.

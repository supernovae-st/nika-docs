`Nika` is one application seam around the engine. Your product owns the
request, interface and business state. Nika owns parsing, admission,
execution, policy, events, receipts and traces.

```ts
import { Nika } from '@supernovae-st/nika-client'

const local = new Nika({ cwd: process.cwd() })
const remote = new Nika({
  url: 'https://nika.example.com',
  token: process.env.NIKA_TOKEN!,
})
```

Omit `url` for the native-process transport. Supply `url` and `token` for the
HTTP transport. A contained served name such as `flows/release.nika.yaml`
goes directly to the resident without a local binary or source. An explicit
local path such as `./flows/release.nika.yaml` uses a compatible local engine
to capture immutable bytes before HTTP admission.

## One lifecycle vocabulary

| Intent | Method | Authority |
|---|---|---|
| Audit | `check(workflow, options?)` | Engine |
| Admit | `await run(workflow, options?)` | Engine or server |
| Observe | `events(run, options?)` | Run session |
| Settle | `await run.done` | Run session |
| Cancel | `cancel(run)` | Run session |
| Verify proof | `traceVerify(receipt, options?)` | Engine |
| Recover a durable job | `attachRun(id, options?)` | HTTP only |
| Read live status | `status(run)` | HTTP only |
| Discover workflows | `listWorkflows()` · `workflow(name)` | HTTP only |
| Manage one schedule | `schedule()` · `scheduleStatus()` | HTTP only |

`run()` returns after stable admission. It does not return a terminal result.
Events are additive and optional to render; `run.done` is the only terminal
truth for that observation leg, including a pause. A paused durable job may
later resume under engine authority. An admitted workflow failure resolves
as result data. Configuration, compatibility, transport and protocol failures
throw typed SDK errors.

## Authority boundary

- The SDK does not parse a second Nika language.
- It does not reconstruct traces or receipts in TypeScript.
- An observer `AbortSignal` does not cancel a run; call `cancel(run)`.
- It does not infer success from an event kind.
- It exposes only the candidate engine's supported routes.

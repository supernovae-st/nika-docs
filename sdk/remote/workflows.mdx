```ts
const names = await nika.listWorkflows()

for (const name of names) {
  const metadata = await nika.workflow(name)
  console.log(metadata.workflow)
}
```

`listWorkflows()` returns the served names, each the workflow's path from the
project root (`workflows/release.nika`). `workflow(name)` confirms that a
served name exists: it returns `{ workflow }` and answers `not_found` (404)
otherwise. In 0.124.1 the metadata is closed to that one field: the server
exposes no declared inputs or description over HTTP.

The client has no pagination, reload or raw-source methods. The server
controls its served directory (`--workflows`); applications should not infer
filesystem paths or ask the API to reveal workflow bytes.

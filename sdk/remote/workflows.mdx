```ts
const names = await nika.listWorkflows()

for (const name of names) {
  const metadata = await nika.workflow(name)
  console.log(metadata.workflow)
}
```

`listWorkflows()` returns contained workflow names. `workflow(name)` returns
path-free, engine-owned metadata with an open additive shape.

The `0.116.2` client has no pagination, reload or raw-source methods. The
resident server controls its configured workflow root; applications should
not infer filesystem paths or ask the public API to reveal YAML bytes.

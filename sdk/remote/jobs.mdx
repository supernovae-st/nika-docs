## Admit and persist identity

```ts
const run = await nika.run('release.nika.yaml', {
  idempotencyKey: crypto.randomUUID(),
})

await database.runs.insert({ jobId: run.id, lastEventId: 0 })
```

HTTP admission captures workflow bytes locally, then submits `POST /v1/jobs`.
Remote run options currently accept `idempotencyKey`; `vars`, `model` and
`maxCostUsd` are refused because their request envelopes do not exist.

## Observe and settle

```ts
for await (const event of nika.events(run)) {
  if (event.sequence !== undefined) {
    await saveCheckpoint(run.id, event.sequence)
  }
}

const result = await run.done
```

## Recover after a process restart

```ts
const recovered = await nika.attachRun(saved.jobId, {
  lastEventId: saved.lastEventSequence,
})

for await (const event of nika.events(recovered)) {
  if (event.sequence !== undefined) {
    await saveCheckpoint(recovered.id, event.sequence)
  }
}

const result = await recovered.done
```

Persist the job id and the last durably consumed sequence. Reattachment avoids
resubmitting a workflow merely because the Node process restarted.

## Read status or cancel

```ts
console.log(await nika.status(run))
const cancellation = await nika.cancel(run)
const result = await run.done
```

OpenAPI `0.116.0` exposes `POST /v1/jobs/{id}/cancel`; cancellation is not a
404. The API has no job-list route, so application indexes remain
application-owned.

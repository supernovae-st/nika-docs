OpenAPI `0.116.0` has no artifact list, download or streaming route, and One
SDK exposes no artifact methods. Do not construct URLs or convenience methods
that the server does not advertise.

Engine-owned outputs arrive on events and the terminal result:

```ts
for await (const event of nika.events(run)) {
  if (event.outputs) preview(event.outputs)
}

const result = await run.done
await persistOutputs(run.id, result.outputs)
```

`outputs` is `Record<string, unknown>` because the workflow defines its own
shape. Validate it at the application boundary before mapping it into business
state.

When a workflow writes files, the engine owns their placement and authority.
Remote retrieval requires a separate application-controlled store until a
future published OpenAPI contract adds artifact routes.

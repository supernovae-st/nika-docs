The candidate SDK exposes no webhook verifier, and the server OpenAPI exposes no
webhook registration or delivery routes. Do not call an SDK static verifier or
claim a Nika signature format.

If your application emits webhooks after `run.done`, that is an
application-owned integration:

```ts
const result = await run.done

await applicationWebhookQueue.enqueue({
  runId: run.id,
  status: result.status,
  outputs: result.outputs,
})
```

Use the receiving platform's published signing library and contract. Store the
Nika run id and receipt alongside delivery state so workflow proof and webhook
delivery remain separate authorities.

## Admit, observe and settle

```ts
const run = await nika.run('workflows/release.nika.yaml', {
  maxCostUsd: 0.25,
})

const watching = (async () => {
  for await (const event of nika.events(run)) {
    timeline.accept(event)
  }
})()

const result = await run.done
await watching

if (result.status !== 'succeeded') {
  process.exit(result.exitCode ?? 1)
}
```

`run()` is asynchronous admission and returns a `NikaRun` containing `id` and
`done`. The run itself is not an async iterator. Subscribe through
`nika.events(run)`; terminal truth lives only in `run.done`.

## Stop observation without cancelling

```ts
const observer = new AbortController()

for await (const event of nika.events(run, {
  signal: observer.signal,
  bufferSize: 64,
})) {
  timeline.accept(event)
}
```

Aborting the observer stops only that view. It never cancels engine work.

## Cancel explicitly

```ts
const cancellation = await nika.cancel(run)
const result = await run.done

console.log(cancellation.accepted, result.status)
```

Cancellation is idempotent for a run owned by this client. Passing a run from
another client instance throws `NikaRunOwnershipError`.

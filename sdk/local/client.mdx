## Construct the client

```ts
import { Nika } from '@supernovae-st/nika-client'

const nika = new Nika({
  bin: '/opt/nika/bin/nika',
  cwd: '/srv/workflows',
})
```

Both options are optional. Binary resolution is strict: explicit `bin`, then
`NIKA_BIN`, then the exact optional platform package. The client refuses an
implicit `PATH` lookup. `cwd` anchors relative workflow paths and project
discovery.

## Probe compatibility with a check

The One SDK has no separate version method. Make a real, read-only check at
startup when the application cannot operate without Nika:

```ts
const report = await nika.check('workflows/health.nika.yaml', {
  nativeStrict: true,
})

if (!report.clean) console.error(report)
```

The engine owns the open report shape. Known fields aid TypeScript completion;
future engine fields pass through unchanged.

## Native method boundary

Local mode supports `check`, `run`, `events`, `cancel` and `traceVerify`.
`attachRun`, `status`, workflow discovery and schedules require resident HTTP
authority and return typed compatibility errors in native mode.

<Info>
  The driver spawns a binary with an argv array. This protects the application
  seam from shell interpolation; the engine still enforces permits, secrets,
  spend and its hardened runtime floor.
</Info>

Golden testing is an engine CLI operation:

```sh
nika test workflows/release.nika.yaml
nika test workflows/release.nika.yaml --update
```

One SDK `0.116.2` does not duplicate that command as a client method. Receipt
verification is part of the SDK because it belongs to the run lifecycle.

```ts
const run = await nika.run('workflows/release.nika.yaml')
const result = await run.done

if (!result.receipt) throw new Error('run did not issue a receipt')

const verdict = await nika.traceVerify(result.receipt)
if (!verdict.verified) {
  throw new Error(verdict.output ?? verdict.reason ?? 'trace verification failed')
}
```

`traceVerify(receipt)` accepts an engine-issued `NikaReceipt` object only. It does not
accept a path and does not reconstruct or verify the chain in TypeScript.

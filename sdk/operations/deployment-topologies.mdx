The word “server” hides several boundaries. Start with who initiates work and
what protocol crosses the process edge.

## Decision table

| Need | Use | Status | Boundary |
|---|---|---|---|
| Product code starts a workflow | local `Nika` | Published npm 0.124.1 (bundled engine) | native process |
| The project clock starts work | `nika serve` (no `--bind`) | Live | `nika.yaml arm[]` to the resident firer |
| An application admits jobs over HTTP | `Nika` + `nika serve --bind` | Published SDK · released engine | Bearer + OpenAPI · cancellation requests an action |
| The host scheduler starts work | `nika arm --emit` | Live | launchd or systemd to `nika arm fire` |
| The engine needs local inference | `nika model serve` | Live | Loopback OpenAI-compatible model API |

## Request-driven application

<LocalContract sdk={SDK} />

```ts
const run = await nika.run('workflows/support.nika', {
  inputs: { ticket: request.id },
})

for await (const event of run.events()) render(event)
const result = await run.result()
```

The application owns the user experience and cancellation. The engine owns
workflow admission, execution and the receipt. `inputs` carries literal
typed values — see [configuration](/sdk/reference/configuration) for why
the deprecated `vars` operator channel is not the app door.

## Clock-driven project

```text
container / bare VM ── nika serve ──────┐
                                         ├── one firer ── run + ledger
managed host ───────── launchd / systemd ┘
```

Both lanes consume the same `arm:` registry. Choose based on who should own
process lifetime and wakeups, not because one lane changes workflow semantics.

## Inference provider

```sh
nika model pull unsloth/Qwen3-4B-Instruct-2507-GGUF
nika model serve --model unsloth/Qwen3-4B-Instruct-2507-GGUF --port 8712
```

This process serves a pulled Qwen3-family model on loopback for the engine to
call (`NIKA_LLAMACPP_BASE_URL=http://127.0.0.1:8712`, then
`model: llamacpp/<model id>`). It does not accept Nika workflow jobs.

## Loopback HTTP (opt-in)

<RemoteContract sdk={SDK} />

`nika serve --bind` is not `nika model serve`, and it is not bare `nika serve`.
The pinned OpenAPI exposes cancellation as an action; the runtime's
settlement determines the result. A settled job's artifacts, listed from its
sealed journal, download over the same door
([Outputs and artifacts](/sdk/remote/artifacts)). Job listing and
`POST /v1/run` remain absent.

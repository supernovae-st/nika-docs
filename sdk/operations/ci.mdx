The pull-request job should prove the file is clean, inspect the authority and
spend shape, then rehearse the graph with the mock provider.

## Admission script

```ts
import { Nika } from '@supernovae-st/nika-client'

const nika = new Nika()
const file = process.argv[2]
const report = await nika.check(file, {
  model: 'mock/echo',
  nativeStrict: true,
})

if (!report.clean) {
  console.error(report)
  process.exit(2)
}

const run = await nika.run(file, {
  model: 'mock/echo',
  maxCostUsd: 0,
})

for await (const event of nika.events(run)) console.log(event)
const result = await run.done
if (result.status !== 'succeeded') process.exit(result.exitCode ?? 1)
```

## Authority ladder

<div className="sdk-flight">
  <span>CI ADMISSION · SECRETS ARRIVE LAST</span>
  <pre tabIndex={0}>{`pull request
    │
    ├── check ───── engine-owned admission report
    └── mock run ── graph behavior · receipt
                         │ approved
                         ▼
protected job ───── provider secrets + deployment authority`}</pre>
</div>

The review job needs no provider key. Protected execution receives only the
authority its environment and workflow declare.

## Pin and print both versions

```sh
nika --version
npm ls @supernovae-st/nika-client
```

Keep the engine and SDK release train visible in logs. Do not debug skew from
an implicit global binary.

<Warning>
  Keep this example gated until
  the pending SDK and engine candidates are published and their artifacts
  pinned. `npm view @supernovae-st/nika-client@0.118.1 version` can check
  registry availability; source readiness does not prove a package is pinned
  in CI or that the matching engine artifact is installed.
</Warning>

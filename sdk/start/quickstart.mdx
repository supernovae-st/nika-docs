The default client is local. It needs no server or token, but it does need
Node.js 22 or newer and a compatible Nika engine.

## 1. Verify what is installable

```sh
brew install supernovae-st/tap/nika
nika --version
npm view @supernovae-st/nika-client@0.116.2 version
```

The engine release and code below use the reviewed `0.116.2` contract. Install
the package only after the pinned registry query reports that exact version:

```sh
npm install @supernovae-st/nika-client@0.116.2
```

## 2. Create a project and workflow

```sh
nika init --project-file
mkdir -p workflows
nika new 01-hello workflows/hello.nika.yaml
```

Keep the generated `.nika.yaml` workflow in your application, for example as
`workflows/hello.nika.yaml`.

`nika.yaml` is the project control plane; `workflows/hello.nika.yaml` is the
executable workflow. Pass only the latter to `check()` and `run()`.

## 3. Check, admit, observe, settle

```ts
import { Nika } from '@supernovae-st/nika-client'

const nika = new Nika({ cwd: process.cwd() })
const file = 'workflows/hello.nika.yaml'
const report = await nika.check(file, { nativeStrict: true })

if (!report.clean) {
  console.error(report)
  process.exit(2)
}

const run = await nika.run(file, {
  model: 'mock/echo',
  maxCostUsd: 0,
})

const watching = (async () => {
  for await (const event of nika.events(run)) {
    console.log(event.kind, event.status)
  }
})()

const result = await run.done
await watching

if (result.status !== 'succeeded') process.exit(result.exitCode ?? 1)
console.log(result.outputs, result.receipt)
```

`run()` resolves after stable admission. `nika.events(run)` is the live,
additive journal view. `run.done` is the only terminal result; an admitted
workflow failure resolves as `status: "failed"` instead of throwing.

## 4. Verify engine-issued proof

```ts
if (!result.receipt) throw new Error('run did not issue a receipt')

const proof = await nika.traceVerify(result.receipt)
if (!proof.verified) {
  throw new Error(proof.output ?? proof.reason ?? 'trace verification failed')
}
```

Pass the receipt object back unchanged. The SDK transports proof; the engine
owns verification.

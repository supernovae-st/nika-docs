## Shared bounds

```ts
interface NikaSharedConfig {
  eventBufferSize?: number      // default 256
  machineBufferBytes?: number   // default 64 KiB
}
```

## Local by default

```ts
interface NikaLocalConfig extends NikaSharedConfig {
  cwd?: string
  bin?: string
}
```

Engine resolution is explicit `bin`, then `NIKA_BIN`, then the exact optional
platform package. Implicit `PATH` lookup is refused.

## Remote when a URL is present

```ts
interface NikaRemoteConfig extends NikaSharedConfig {
  url: string
  token: string
  allowInsecureHttp?: boolean
  requestTimeout?: number       // default 30 seconds
  fetch?: typeof globalThis.fetch
  cwd?: string
  bin?: string
}
```

For an explicit local path, `cwd` and `bin` select the compatible local
engine that captures its immutable snapshot. Contained served names go
directly to the resident and do not require either local source or a binary.

## Operation options

```ts
interface NikaCheckOptions {
  model?: string
  nativeStrict?: boolean
  signal?: AbortSignal
}

interface NikaRunOptions {
  vars?: Record<string, string | number | boolean>
  model?: string
  maxCostUsd?: number
  idempotencyKey?: string
}

interface NikaEventsOptions {
  signal?: AbortSignal
  bufferSize?: number
}

interface NikaAttachRunOptions { lastEventId?: number }
interface NikaTraceVerifyOptions { signal?: AbortSignal }
```

Remote `check` refuses `model` and `nativeStrict`. Remote `run` accepts
`idempotencyKey` but refuses `vars`, `model` and `maxCostUsd` until the HTTP
request envelope can carry them. Signals stop a request or observer; only
`cancel(run)` requests cancellation of admitted work; `run.done` carries the
actual outcome.

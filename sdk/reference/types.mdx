## Run lifecycle

```ts
interface NikaRun {
  readonly id: string
  readonly done: Promise<NikaRunResult>
}

interface NikaRunResult {
  id: string
  status: NikaRunStatus
  transport: 'native-process' | 'http'
  exitCode?: number
  outputs?: Record<string, unknown>
  receipt?: NikaReceipt
  error?: NikaMachineError
  [key: string]: unknown
}
```

`NikaRunStatus`, `NikaEvent`, `NikaCheckResult` and engine-owned metadata are
additive. Known words aid completion without closing the vocabulary.

## Events and proof

```ts
interface NikaEvent {
  kind?: string
  status?: NikaRunStatus
  sequence?: number
  receipt?: NikaReceipt
  outputs?: Record<string, unknown>
  [key: string]: unknown
}

type NikaReceipt = Readonly<Record<string, unknown>>

interface NikaTraceVerifyResult {
  verified: boolean
  verdict?: 'verified' | 'invalid' | 'unavailable' | (string & {})
  reason?: string
  trace_id?: string
  exitCode?: number
  output?: string
  [key: string]: unknown
}
```

## Errors

```text
NikaError
├── NikaConfigurationError
├── NikaTransportError
│   └── NikaProtocolError
├── NikaCompatibilityError
├── NikaOperationError
├── NikaEventBufferOverflowError
└── NikaRunOwnershipError

NikaEngineUnavailable
```

`NikaEngineUnavailable` is exported separately by binary resolution. Schedule
types are exported for the exact CAS-backed resident schedule contract; inspect
the pinned source declarations for their additive engine-owned fields.

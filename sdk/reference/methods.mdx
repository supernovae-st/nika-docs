| Method | Returns | Local | HTTP |
|---|---|:---:|:---:|
| `check(workflow, options?)` | `Promise<NikaCheckResult>` | yes | yes |
| `run(workflow, options?)` | `Promise<NikaRun>` | yes | yes |
| `events(run, options?)` | `AsyncIterable<NikaEvent>` | yes | yes |
| `cancel(run)` | `Promise<NikaCancelResult>` | yes | yes |
| `traceVerify(receipt, options?)` | `Promise<NikaTraceVerifyResult>` | yes | typed unavailable verdict currently |
| `attachRun(id, options?)` | `Promise<NikaRun>` | no | yes |
| `status(run)` | `Promise<NikaRunStatus>` | no | yes |
| `listWorkflows()` | `Promise<readonly string[]>` | no | yes |
| `workflow(name)` | `Promise<NikaWorkflowMetadata>` | no | yes |
| `schedule(workflow, options)` | `Promise<NikaScheduleApplyResult>` | no | yes |
| `scheduleStatus(id)` | `Promise<NikaScheduleStatus>` | no | yes |

`run.done` is the result for one observation leg, including a pause.
`check()` returns the engine's local findings report or the resident's typed
served-name acknowledgement/refusal, depending on admission form.
`cancel()` may acknowledge a pending action; it never replaces `run.done`.
Methods that require resident
authority return typed compatibility errors in native mode. `events`,
`cancel`, and `status` accept only a run owned by that client instance.

The facade intentionally has no version, plan, buffered-run, golden-test,
health, webhook, artifact or environment-constructor convenience methods.

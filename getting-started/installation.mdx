<Warning>
  **v{STATUS.version} is a pre-release Diamond rebuild.** The `nika` binary
  is not yet admitted — admission lands around Round 17 (L5 binary, wiring
  L4 interfaces). Until then there are no release artifacts, no
  `nika --version`, no `nika doctor`. This page shows (1) how to track
  releases today, and (2) what the install flow will look like at v0.81
  — the first usable ship (language v0.1 + vertical slice · summer 2026).
</Warning>

## How to track today

<Steps>
  <Step title="Watch the GitHub repo">
    [github.com/supernovae-st/nika](https://github.com/supernovae-st/nika) —
    star + watch for releases. Every crate admission is an atomic commit
    and (once the binary ships) the `v0.81.0` tag.
  </Step>

  <Step title="Follow the live constellation">
    [Constellation](/reference/constellation) tracks every admitted, WIP,
    and planned crate. [Live state](/reference/status) auto-refreshes
    from `scripts/refresh-status.sh` on every push.
  </Step>

  <Step title="Read the ADRs">
    35 architecture decision records (30 Accepted + 5 Proposed) shape
    everything being built. [ADR directory on GitHub](https://github.com/supernovae-st/nika/tree/main/docs/adr).
  </Step>

  <Step title="Clone and build from source (optional)">
    Today's engine compiles and tests pass on every push. The binary
    entrypoint doesn't exist yet, but you can explore the workspace:

    ```bash
    git clone git@github.com:supernovae-st/nika.git
    cd nika
    git checkout main
    cargo test --workspace --lib    # 905 tests, always --lib (avoids Keychain popup)
    cargo doc --no-deps --open      # browse the admitted crates' rustdoc
    ```
  </Step>
</Steps>

## Target install flow (v0.81 · summer 2026)

When the `nika` binary admits, the install flow will be:

<Tabs>
  <Tab title="curl">
    ```bash target — v0.81
    curl -LsSf https://nika.sh/install.sh | sh
    ```
    Detects platform (macOS / Linux), prefers Homebrew if available,
    falls back to the GitHub release binary with signature verification.
  </Tab>

  <Tab title="Homebrew">
    ```bash target — v0.81
    brew tap supernovae-st/nika
    brew install nika
    ```
  </Tab>

  <Tab title="cargo">
    ```bash target — v0.81
    cargo install nika --locked
    ```
    From crates.io once the binary publishes. Source install via
    `cargo install --git` works today against the `main` branch
    (but the binary crate is `publish = false` until the workspace is
    stable).
  </Tab>
</Tabs>

## Target first-run verification

```bash target — v0.81
nika --version
nika doctor    # checks keys, providers, system, schema
```

`nika doctor` will be the first thing to run after install. It tells you
what's missing (provider keys, network access, write permissions,
catalog freshness) and how to fix it.

## Trust but verify

When release artifacts ship:

<Check>
  The install script will live at [nika.sh/install.sh](https://nika.sh/install.sh).
  **Read it before piping to `sh`.** It's ~80 lines of pure POSIX.

  All release binaries will be signed (Sigstore keyless) and published at
  [github.com/supernovae-st/nika/releases](https://github.com/supernovae-st/nika/releases)
  with SHA256 sums + provenance attestations.
</Check>

## Provider keys

Nika needs a provider to run inference — local needs no key at all. At v0.81:

```bash target — v0.81
# Local · zero key (Ollama daemon)
ollama pull llama3.1

# Or export any cloud provider key (ephemeral)
export MISTRAL_API_KEY=...
export ANTHROPIC_API_KEY=sk-ant-...

# System keychain (persistent, recommended for cloud)
nika keys add mistral
```

See [Providers catalog](/reference/providers-catalog) for all
{STATUS.providers} providers with their env var names.

## What gets installed at v0.81

- **`nika`** — the binary (single file, no daemon, no background process)
- **Shell completions** (bash / zsh / fish) — auto-installed by the curl script
- **Nothing else.** No service, no telemetry, no home-dir pollution beyond
  `~/.config/nika/` (catalog cache) and `~/.local/state/nika/` (NDJSON logs,
  opt-out).

## Uninstall

```bash target — v0.81
# Homebrew
brew uninstall nika

# Manual install
rm /usr/local/bin/nika
rm -rf ~/.config/nika ~/.local/state/nika
```

# Security Policy

This repository carries the source of **docs.nika.sh** (Mintlify).
Security-relevant surface here · published documentation that readers
copy-paste (commands · workflow snippets) and the served `llms.txt`
consumed by agents.

## Supported Versions

Only `main` is supported · the docs deploy from it.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub
issues, discussions, or pull requests.**

Send an email to **security@supernovae.studio** with ·

- A description of the issue (e.g. a doc instructing an unsafe command ·
  content injection in the published site)
- The page URL or commit SHA where you observed it

We acknowledge receipt within **72 hours** and aim for a substantive
response (initial triage + ETA) within **7 days**.

## Disclosure Process

1. **Triage** · maintainers verify the report and confirm the scope
2. **Fix development** · patch authored privately
3. **Public release** · fix deployed · advisory when warranted
4. **Credit** · reporter named unless anonymity is requested

We aim for **≤90 days** between report and public disclosure, shorter for
actively-exploited issues.

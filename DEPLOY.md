# Documentation publication

The documentation is served at `https://docs.nika.sh` by Mintlify from this
repository's `main` branch. `docs.json` owns the public navigation.

Before merging, run the publication audit, link audit and applicable source
projection and example checks. After a deployment, verify the changed pages
and the generated documentation index on the public domain. A successful Git
merge alone does not establish that a page is deployed.

All tracked content is public, even if it is absent from the navigation.
Keep operational runbooks and unpublished project material outside this
repository. Removing a page from navigation does not restrict access to its
source or copies already published.
